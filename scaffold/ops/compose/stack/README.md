# Full-stack compose

Generated by `stack-kit compose-gen` into this folder.

Each service loads its module's env files from the secrets root (the manifest's `secrets`, `ops/config`
by default): `<secrets root>/<module's secrets folder>/.env` and `.env.<environment>`.

```powershell
stack-kit stack up -d --build
stack-kit stack --prod up -d --build
```
